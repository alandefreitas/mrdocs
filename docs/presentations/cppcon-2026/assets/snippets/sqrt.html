sqrt

Computes the integer square root \(\lfloor\sqrt{value}\rfloor\).

Synopsis

Declared in <sqrt.hpp>

template<typename T>
T
sqrt(T value)
requires std::is_integral_v<T>;

Description

This function calculates the square root of a given integral value using bit manipulation, in \(O(\log value)\) time.

Exceptions

NameThrown on
std::invalid_argumentif the input value is negative.

Return Value

The square root of the input value.

Template Parameters

NameDescription
TThe type of the input value. Must be an integral type.

Parameters

NameDescription
valueThe integral value to compute the square root of.
