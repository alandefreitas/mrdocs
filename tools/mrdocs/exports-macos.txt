# The only symbols the mrdocs executable exports: every one whose Itanium
# mangling is in the mrdocs namespace (functions and member functions with any
# qualifier, static locals and thread-locals) and the type information,
# vtables, thunks and guard variables of its types. Everything else, including
# what the static libraries (LLVM, Clang, Lua, JerryScript) define, stays local
# to the executable, so that a plugin which bundles a copy of one of those
# libraries binds to its own copy.
